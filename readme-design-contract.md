# README Design Contract

## readmeArchetype
Sensory cupping notes.

## readmeNarrativeVoice
Measured tea educator using short observational phrases.

## readmeSectionPattern
Flight card, leaf and water, fold rules, shared palate, steep commands, final rinse.

## readmeMotif
An annotated tasting flight card with stains and margin notes.

## requiredFactsPlacement
The flight card holds identity and live coordinates. Leaf and water explains state. Fold rules combines consensus, guards, methods, and validator rejection. Shared palate explains the frontend and visual system. Steep commands holds setup and tests. Final rinse holds deployment and limits.

## bannedReadmePatterns
No accession file, service transcript, generic feature list, standard setup heading, or verification matrix.

## proofOfDifference
Unlike Archive Lantern's registrar dossier, this document begins as a tasting card, uses sensory vocabulary, and mixes compact definitions with a steeping recipe.
